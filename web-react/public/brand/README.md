# ChargeSync brand assets

`chargesync-icon.png` is the transparent emblem used by the shared `BrandLogo`
component and browser favicon. The component renders the name and tagline as
accessible HTML text, with sizes and colors for dark and light surfaces.

`chargesync-logo.png` preserves the supplied reference artwork.

The icon was prepared with the built-in imagegen tool using this prompt:

> Use case: background-extraction. Edit target: supplied ChargeSync logo photo. Extract ONLY the cyan/teal circular C with the lime-to-green diagonal lightning bolt symbol above the lettering. Remove all lettering, tagline, horizontal rules, textured dark photo background and cast shadows. Preserve the exact silhouette, bolt angles, C shape and blue/cyan/teal/green gradients of the original symbol. Do not redesign. Output clean crisp isolated emblem on true alpha transparent background, square canvas, symbol centered and filling 90% of canvas with small even margins. This is a production website brand icon that must work on both white and dark backgrounds. No text, no black plaque, no glow, no border, no scene.
